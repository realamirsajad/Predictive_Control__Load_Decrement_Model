## Code Developer
* **Ali Majidi**

  Matlab scripts and Simulink models uploaded enable the user to model, simulate, and evaluate the dynamic performance of Model Predictive Control (MPC) strategy within an interconnected two-area power system. The reason that MATLAB is used for this purpose is that it provides a suitable computational platform to implement the detailed mathematical state-space representation of each control area, integrating essential structural components such as the centralized generator, governor, turbine, and the associated tie-line dynamics. Furthermore, the software facilitates the execution of the Luenberger state observer design using the Ackerman method, the formulation of operational constraints, and the optimization of classical benchmarks (integral and proportional-integral controllers) via the Particle Swarm Optimization (PSO) algorithm. This enables robust simulation testing under varying load disturbances and severe parameter uncertainties to confirm the superiority, stability, and transient damping capabilities of the developed predictive controller. In addition to MATLAB works, relevant output figures have been uploaded withing corresponding folders.
